# Chamber Brief Bank

A mobile-friendly, web-based legal document repository built for law chambers. 
It enables counsels to search, view, and download court briefs while giving the Director of Litigation administrative control to upload, tag, and manage legal files.

## Tech Stack
- Frontend: Vite + React + CSS
- Backend & Storage: Supabase (Auth, PostgreSQL Database, Blob Storage)

## Local Quick Start
1. Open project directory in terminal
2. Install dependencies: `npm install`
3. Start local server: `npm run dev`
4. Start network host for mobile testing: `npm run dev -- --host`
5. Access locally at `http://localhost:5173`
